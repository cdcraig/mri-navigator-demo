Why the boundary is the whole argument. A guardrail written into a prompt lives inside the dashed box. It is one clever question away from being talked around, and it has to be rewritten into every persona — so Eva and Evan drift apart the moment someone edits one of them. Every guard in this graph is ordinary deterministic code sitting outside the box: one implementation, centrally maintained, applied identically to Eva, to Evan, and to any persona added later. The model is never asked to police itself, and a blocked message never reaches it at all.
